# Projet tifosi - Base de données

Ce projet contient la création et gestion d'une base de données pour un restaurant , "Le Tifosi". 

## Structure du dépôt
- `schema.sql` : Contient le script de création de la base de données et des tables.
- `data_insertion.sql` : Contient les données de test à insérer dans la base de données.
- `queries.sql` : Contient les requêtes de test à exécuter pour vérifier la bonne création et l'intégrité des données.

## Comment exécuter les scripts
1. Crée une base de données vide en utilisant le script `schema.sql`.
2. Exécute le script `data_insertion.sql` pour peupler la base de données avec les données de test.
3. Utilise le script `queries.sql` pour tester les requêtes sur la base de données.
